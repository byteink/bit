# Guides

search box, start to finish, with a program you can paste and run.

For what a language construct means, see the
[language reference](../reference/README.md). For every function a module
exports, see the [standard library reference](../stdlib/README.md). These
guides link out to both rather than restating them.

2. [Serve JSON over HTTP](serve-json-over-http.md)
3. [Handle errors without exceptions](handle-errors.md)
4. [Test your code](test-your-code.md)
5. [Run work in parallel](run-work-in-parallel.md)
6. [Ship a single binary](ship-a-single-binary.md)
