# Bit documentation

New here? [Get started](get-started.md) installs Bit and runs your first
program. Everything else on the site is one of five sections, each with one
job:

| Section | Start here | Job |
| --- | --- | --- |
| The Bit Book | [book/README.md](book/README.md) | The story: build Inkwell, a notes tool that grows into a small blogging API, and learn every concept as the app needs it. |
| Language | [reference/README.md](reference/README.md) | Each language concept, defined once, exactly and short. No story. |
| Standard library | [stdlib/README.md](stdlib/README.md) | What each `std/*` module is for and how to use it. |
| Packages | `pkg/<name>/README.md` | First-party packages: what each one solves and how to add it to a project. |
| Tools | [tools/README.md](tools/README.md) | The `bit` command: build, run, test, fmt, lint, and the package manager. |

A concept is taught once, in the Book, and defined once, on its Language or
Standard library page - the Book links to the definition instead of
repeating it, and a reference page links back to the Book chapter that uses
it instead of telling its own story.
