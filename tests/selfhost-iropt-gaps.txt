# Expected POST-opt IR divergences between the Zig seed (`bit-seed`) and the
# self-hosted compiler (`bit`), consumed by scripts/selfhost-diffiropt.sh.
#
# This file is the gate, not a note. The script fails when a path ENTERS this
# set (a new regression) AND when one LEAVES it (a gap that closed and was not
# deleted here). Both directions matter: the script used to print `MISMATCH=3`,
# name one file, and exit 0 — it could not fail at all, and a known gap closing
# as a real regression opened would have read as "no change" (#1478).
#
# Format: one repo-relative path per line, `# reason` after it. Every entry
# needs a reason naming the underlying defect — an entry that only says "known"
# is an excuse, not a gap.
#
# This is a SUBSET of tests/selfhost-ir-gaps.txt (the pre-opt set), which is
# what you would expect: the optimizer cannot introduce a divergence the
# lowering did not already carry, and `run_generic_composite_result.bit`
# diverges before the optimizer but converges after it.
#
# Shrinking this list is the point. Delete an entry the moment its cause is
# fixed; the gate will tell you when that happens.

# --- FloatLit formatting parity — CLOSED (#1539) ---
# `run_float_bitexact.bit` and `run_float_round.bit` were here, for the same
# cause recorded in tests/selfhost-ir-gaps.txt: not the conversion ALGORITHM,
# but a 32-byte output buffer in `bit_rt_string_from_float`. Zig's `{d}` on an
# f64 is positional decimal always, so the extremes run to 327 characters; the
# `NoSpaceLeft` that `bufPrint` returned hit a `catch unreachable` in a
# ReleaseSmall archive, which is undefined behaviour rather than a panic and
# degraded to a silently truncated string.

# --- Generic type substitution in lowering: RETIRED (#1540) ---
# `run_generic_nested.bit` was here and is now closed — `lowerFieldAccess` took a
# field read's type off the declared field node instead of the checker's already
# substituted `checkMember` answer. See tests/selfhost-ir-gaps.txt for the full
# account.

# is the numeric value of two `$t<id>`s, because the seed interns a template's
# substituted method signatures INSIDE the instantiation while `bit` copies them
# in a later pass. Full account in tests/selfhost-ir-gaps.txt.
