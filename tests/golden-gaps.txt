# differ from the checked-in `.expected`, one per line as `name  # reason`.
# Blank lines and full-line comments are ignored; the `#` reason is MANDATORY —
# a bare name is rejected, so no entry can exist without a stated cause.
#
# tests/bit/golden.bit drives the real `bit` CLI. tests/harness.zig, which it
# replaces, ran every `// error` case through `bit.compileReport` — the SEED, in
# process (tests/harness.zig:249) — so the shipped compiler's diagnostics were
# never covered by this corpus at all. Porting the gate to the real binary
# exposes every seed-vs-shipped diagnostic gap at once, and this file is where
# the ones that are DELIBERATE are written down.
#
# The gate is on the SET, not a count. A name listed here that now matches its
# `.expected` is a STALE gap and FAILS the run, so a gap closing while another
# opens cannot cancel out; a name listed here that is not in the corpus fails
# too, so a deleted case cannot leave a permanent excuse behind. Deleting a line
# is how a gap is retired — that is the intended churn.
#
# Do not add to this list to make a run green. Every entry is a diagnostic the
# shipped compiler owes, with a ticket's worth of work behind it.
