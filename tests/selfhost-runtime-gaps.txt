# Runtime files whose lowered IR is EXPECTED to differ between the pinned stage0
# and the working tree. Read by scripts/selfhost-diffruntime.sh (#1859), which
# fails when a path ENTERS or LEAVES this set — a swap at constant count is a
# failure, which is the whole point.
#
# Everything here today is #1857 and nothing else. The pinned stage0 is 0.1.3,
# which predates the hex-float fix: its `parseFloat` has no `0x…p…` branch, so it
# lowers every hex float literal to ±0.0 while the working tree lowers the real
# value. These two files are the only ones in `runtime/` carrying such literals.
#
# THESE TWO LINES ARE DELETED WHEN stage0 IS REPINNED TO 0.1.4. At that point
# both sides carry the fix, the files agree, and the gate will FAIL until they
# are removed from here — which is the correct and intended way to find out.
runtime/root/floatslog.bit
runtime/root/floatsatan.bit
