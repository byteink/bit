## Method

Parse throughput of pkg/yaml against gopkg.in/yaml.v3 (Go) and goccy/go-yaml (Go), one process per timed run, trimmed mean of 15 runs (slowest fifth dropped, mean of the rest; see run.sh's `trimmean` for the estimator). Every implementation is proven to parse each fixture to the same document count, node count and CRC-32C checksum before anything is timed; the transcript is at the end of this file.

Every competitor is cross-compiled for this host inside a throwaway docker container (a Go image for Go, a cargo-zigbuild image for C, C++ and Rust; CGO_ENABLED=0 for Go, both are pure Go) and then run NATIVELY on the host, timed by the same `time_run` (a microsecond wall clock around the process, peak RSS from `/usr/bin/time -l`) as the Bit binary. No Go, C, C++ or Rust toolchain is installed on this machine.
